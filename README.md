## 💻 Getting Started Locally

1. Open a terminal in this project folder:
   ```bash
   cd "C:\Users\HP\.gemini\antigravity\scratch\yash-tiwari-portfolio"
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

4. To build for production:
   ```bash
   npm run build
   ```
   The production-ready static assets will be in the `/dist` directory.

## 🌐 1-Click Free Deployment

You can deploy this site in under 2 minutes to any free hosting provider:

### Deploy on Vercel:
1. Push this folder to a GitHub repository (`git init`, `git add .`, `git commit -m "init"`, `git push`).
2. Log into [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository. Vercel will automatically detect Vite and run `npm run build`.

### Deploy on Render (Same as the reference site):
1. Create a **Static Site** on [render.com](https://render.com).
2. Connect your GitHub repository.
3. Set **Build Command** to `npm run build` and **Publish Directory** to `dist`.
